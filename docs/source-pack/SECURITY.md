# Security

Static SVG and Markdown only. No scripts, foreignObject elements, event handlers, external assets, remote trackers, keys or private contact data.
Never alter repository permissions, personal account fields, security settings, GitHub organization, unrelated repositories or upstream website.
Audit against exact Git refs, diff allowlist, SVG syntax, source logo fidelity, README links, provenance and public claim accuracy.
Risk LOW for static presentation; privileged account modifications require a separate gated increment.
